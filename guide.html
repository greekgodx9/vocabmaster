🚀 快速开始

PC 端

浏览器打开 https://vocabmaster5.netlify.app 即可使用。

📱 iPhone / iPad

  1. 用 Safari（必须是 Safari）打开 vocabmaster5.netlify.app
  2. 点击底部 分享按钮 ⬆️
  3. 滑动找到 "Add to Home Screen"（添加到主屏幕）
  4. 点击 "Add"
  5. 桌面上出现 📚 VocabMaster 图标，像原生 App 一样使用

💡 添加到桌面后支持离线使用，不消耗流量。

📝 添加单词

手动输入

  1. 左侧菜单 → "My Words"
  2. 点击 "+ Add Words"
  3. 每行一个单词，格式：单词 : 释义
ephemeral : lasting for a very short time
ubiquitous : present, appearing, or found everywhere
sanction : (n.) official approval; (v.) to impose a penalty

一行支持多个释义，用分号分隔：bank : (n.) river bank; (n.) financial institution; (v.) to tilt

批量导入（CSV / Excel）

  1. 左侧菜单 → "Word Books"
  2. 点击 "+ New Word Book"
  3. 拖拽 CSV 或 Excel 文件到上传区域，或粘贴文本
  4. 设置每天释放多少词（如 20 个/天）
  5. 系统每天自动释放，节奏可控

📥 可下载模板：在导入区域点击 "Download Template"

🤖 AI 生成文章

将你学过的单词编成一篇真实的英文文章，在语境中自然而然地掌握。

  1. 左侧菜单 → "Generate Article"
  2. 勾选要包含的单词（可点 "Select All" / "Today's New" / "Due Today"）
  3. 选择 长度（200 / 300 / 500 / 700 词）和 难度：
    级别适合
    B1-B2 Intermediate高中 / 大学基础，句子清晰易懂
    CET-6六级水平
    IELTS 7-8研究生 / 雅思
    GRE / Academic高阶学术英语
  4. 可选：输入一个 主题（如 climate change 或 space exploration）
  5. 点击 "Generate Article"

⚙️ 首次使用需在 Settings 中配置 AI API Key（推荐 DeepSeek，国内可用且便宜，见下文）。

文章阅读

  • 目标单词被 蓝色（新词） / 黄色（待复习） / 绿色（已掌握） 标记
  • 点击标记单词 → 弹出详细释义和例句
  • 点击页面空白处 → 弹窗消失
  • 点击 🔊 按钮 → 语音朗读全文

🔄 间隔重复复习

基于 SM-2 算法（Anki 同款），在你快忘记时恰好提醒你。

  1. 左侧菜单 → "Review"
  2. 看到单词 → 在脑中回忆释义 → 点击翻面
  3. 根据记忆情况诚实评级：
评级含义下次复习
🔴 Again完全不记得几小时后
🟠 Hard有点印象但不确定几天后
🟢 Good想起来了数周后
🔷 Easy非常熟悉，脱口而出数月后

✏️ 拼写测试

复习完成后可进入拼写模式：看释义 → 输入单词 → 检查拼写。

🔥 每日打卡：Dashboard 上点 "Check In"，Progress 页面查看连续打卡热力图。

👤 账号与同步

☁️ 云同步 ⭐ 推荐

PC 和 iPhone 自动保持数据一致。

  1. Settings → 找到 "👤 Account"
  2. 设置一个 Username（如 alex）和 Password
  3. 点击 "Log In & Sync"
  4. 在另一台设备上：输入完全相同的 Username + Password → Log In & Sync

✅ 登录后自动同步：加单词、复习、打卡后都会自动推送。无需手动操作。不同的人用不同的 Username，数据互不干扰。

❓ 常见问题

Q: 数据安全吗？
A: 数据首先存在浏览器本地。云同步通过 Username + Password 加密隔离，不同人之间数据完全独立。API Key 永远只存你的设备。

Q: 可以离线使用吗？
A: 可以。添加到 iPhone 桌面后，复习、查词等核心功能完全离线。仅 AI 生成文章和云同步需要网络。

Q: 换设备了怎么办？
A: 在新设备 Settings → Account 输入原来的 Username + Password → Log In & Sync，数据自动拉取。或旧设备 Copy All Data → 新设备 Import from File。

Q: 如何备份？
A: 云同步已自动备份。也可定期 Settings → Copy All Data 手动保存。

⚠️ 注意：iOS Safari 在存储空间紧张时可能清理浏览器数据。建议开启云同步以获得自动备份保护。
