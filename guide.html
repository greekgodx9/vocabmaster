📚 VocabMaster 使用完全指南

从零开始配置，到每天高效记单词——完整上手手册

适用于 VocabMaster v2.0  ·  建议阅读时间：15 分钟

软件简介

VocabMaster 是一款运行在浏览器里的英语单词记忆工具，无需安装，双击 index.html 即可使用。它把三件事合为一体：

  • AI 生成有声文章——把你的生词融入一篇高质量英语文章，在语境中理解单词
  • SM-2 间隔复习——基于艾宾浩斯遗忘曲线，在你快要忘记单词的那一刻复习，效率最高
  • 词书计划——导入几千词的词书，每天自动释放固定数量，像"不背单词"一样系统推进

所有数据都储存在你本机浏览器的 localStorage 里，不联网、不上传，完全私密。只有生成文章时需要调用 AI 接口。

💡 学习逻辑一句话概括 今天加入新词 → 生成文章在上下文中感知它 → SM-2 安排复习时间点 → 在快要忘记前复习 → 复习间隔越来越长直到永远记住

三、添加单词

VocabMaster 支持两种加词方式：手动逐条输入和批量导入词书。两者可以同时使用。

方式 A：手动输入（My Words）

适合：每天记录课堂上/阅读中遇到的新词，数量不多但质量高。

1

点击左侧导航 My Words，进入单词库页面。

2

点击右上角 + Add Words 按钮，展开输入区域。

3

在文本框中输入单词，每行一个，支持三种格式：

# 1. 只输入单词（无释义）
ephemeral

# 2. 单词 + 单个释义
ubiquitous : present or found everywhere

# 3. 单词 + 多个释义（用分号分隔，用于「熟词生义」）
bank : (n.) 河岸; (n.) 银行; (v.) 使飞机或汽车倾斜转弯
sanction : (n.) 官方许可与认可; (v.) 对...实施制裁或惩罚
💡 多释义的意义（熟词生义） "bank"是大家都认识的词，但"使飞机倾斜"这个动词义很多人不知道。加入多个释义后，AI 生成文章时会刻意使用那个你不熟悉的义项，强迫你在真实语境中接触生义——这正是"熟词生义"学习法的精髓。
4

点击 Add Words。系统会自动去重，右下角会提示添加了多少个词、跳过了多少个重复词。

My Words 页面功能说明：

功能位置说明
搜索搜索框实时按单词名或释义过滤
筛选状态下拉框New / Learning / Young / Mature 四个掌握阶段
按日期分组📅 By Date 按钮按加入日期分组，方便查看"今天加了哪些词"
删除每行最右侧 ✕点击后弹出确认框再删除
下次复习Next Review 列显示该词下次复习的日期；"Due now"表示现在就该复习了

方式 B：批量导入词书（Word Books）

适合：有一本几百到几千词的词书（如考研5500、雅思高频词、GRE词表），想按计划系统学完。

准备词表文件

支持两种文件格式：

  • CSV 文件（.csv）：用 Excel 或记事本创建，最通用
  • Excel 文件（.xlsx / .xls）：直接用 Excel 创建

点击 Word Books → New Plan → ↓ 下载模版，会自动下载一个模版文件 vocabmaster-template.csv，用 Excel 打开后格式如下：

Word（必填）Definition 1（可选）Definition 2（可选）Definition 3（可选）
ephemerallasting for a very short time
ubiquitouspresent appearing or found everywhere
bank(n.) the side of a river(n.) a financial institution(v.) to tilt an aircraft
💡 填写技巧
  • 第一行是表头（Word, Definition 1...），系统会自动识别并跳过
  • 释义列可以全部留空，只有单词也能导入——生成文章时 AI 会自动在语境中帮你理解
  • 一行多个释义 = 熟词生义，AI 会刻意使用你不熟悉的那个意思
  • Excel 里直接复制粘贴一列单词就行，保存为 .xlsx 或另存为 .csv 都可以

创建学习计划

1

点击左侧导航 Word Books，然后点右上角 + New Plan。

2

Plan Name：给词书取个名字，例如"考研英语词汇5500"、"雅思高频词"。

3

Daily New Words：选择每天学多少个新词。点击快捷按钮（20/30/50/100），或在输入框自定义。

💡 如何选择每日目标？
  • 考研/雅思备考（时间充裕）：50～100 词/天
  • 日常学习维持：20～30 词/天
  • 初学者：20 词/天，先把复习节奏培养起来
注意：新词越多，后续积累的复习量也越大。宁少勿多，保持可持续。
4

Upload File 标签页：将准备好的 CSV 或 Excel 文件拖拽到虚线框，或点击框内「点击选择」按钮选取文件。上传后会看到词表预览（前 8 行），确认内容正确。

或切换到 Paste Text 标签页：直接粘贴文字内容，格式同手动输入（支持 word : 释义1; 释义2）。

5

点击 ▶ Start Plan。系统会立刻释放今天应学的第一批新词到「My Words」，并弹出提示："词书创建成功！今日已释放 N 个新词"。

词书的每日自动释放机制

创建词书后，每次打开软件时，系统会自动计算今天应该释放多少词并加入 My Words：

  • 第 1 天：释放第 1～50 词（假设目标 50/天）
  • 第 2 天：释放第 51～100 词
  • 第 N 天：释放第 (N-1)×50+1 到 N×50 词
  • 如果某天忘记打开软件，下次打开时会补释放累积的词（不会超过一个周期的量）
⚠️ 重要提示 词书只是个"释放队列"。词书里的词并不直接参与复习——被释放后才真正进入 My Words，然后 SM-2 才开始为它安排复习计划。

词书卡片上可以看到：总词数、已释放数、剩余词数、按当前进度预计完成天数。右侧按钮可以暂停（⏸）或删除（🗑）词书，删除词书不影响已经进入 My Words 的词。

四、生成有声文章（Generate Article）

这是 VocabMaster 的核心功能。AI 会根据你选择的单词，生成一篇指定难度的英语文章，你的生词会自然地融入其中，并高亮显示。

选词与生成设置

1

点击左侧导航 Generate Article。

2

Words to Include（选择要融入的单词）：左侧面板顶部是快速选择按钮：

按钮作用
All勾选全部单词
None取消全部勾选
Today New只勾选今天新加入的词（刚学的，最需要在语境中强化）
Today Due只勾选今天到期复习的词
Today All今天的新词 + 今天到期的词合并选中

单词列表按加入日期分组排列，有多个释义的词会在名字后显示 ×2（表示有 2 个释义）。你也可以手动勾选/取消任意单词。

3

Topic（主题）（可选）：给文章设定一个话题，例如 climate change、artificial intelligence、education reform。留空则由 AI 自由选题。

4

Length（长度）：Short（约300词）/ Medium（约500词）/ Long（约700词）。建议日常用 Medium，想深度阅读选 Long。

5

Level（难度）：

  • CET-6：大学英语六级水平，适合四六级备考
  • IELTS 7-8 / Graduate（默认）：雅思高分/研究生英语水平，正式学术文体
  • GRE / Academic：GRE 考试 / 顶级学术英语，词汇复杂、句式精密
6

点击 ✨ Generate Article，等待 5～15 秒，文章会显示在右侧。

阅读生成的文章

文章中用黄色高亮标出了你选中的每一个生词。你可以：

  • 先通读全文，感受生词在真实语境中的用法
  • 看不懂的句子，先猜测意思，然后结合文章底部「Target Words Used」核对
  • 注意有多释义的词——AI 会刻意使用你不熟悉的那个义项（熟词生义效果）

有声朗读功能

文章顶部是 TTS（文字转语音）控制栏：

控件功能
▶ Play开始朗读全文（从头开始）；如果已暂停则继续
⏸ Pause暂停，可再按 Play 继续
⏹ Stop停止，下次 Play 重新从头开始
Speed 滑块调节语速：0.5x（很慢）到 2.0x（很快）。精听建议 0.8x，日常 1.0x，熟悉后 1.2x
Voice 下拉选择朗读声音（根据浏览器和系统可用的英语语音列表）。推荐选标注 en-US 的美式发音
💡 最佳阅读策略
  1. 先静读全文，遇到高亮词尝试根据上下文推断意思
  2. 再精听（Speed 0.8x），跟读或默读，注意每个高亮词的发音和用法
  3. 最后正常速度（1.0x）听一遍，感受自然语流
⚠️ TTS 说明 朗读使用浏览器内置的 Web Speech API，完全本地、免费、无需联网。不同浏览器的语音质量有差异：Chrome 和 Edge 的英语语音质量最好。

五、每日复习（Review）

这是让单词真正留在记忆里的核心环节。使用科学的 SM-2 间隔复习算法，保证在最高效的时间点复习每个词。

SM-2 算法原理（为什么这样安排复习时间）

人类的记忆遵循艾宾浩斯遗忘曲线——学完一个新词后，记忆会随时间衰减，但每次成功回忆都会延长下次遗忘的时间。

SM-2 算法的核心逻辑：

  • 每个单词独立记录：复习间隔（interval）、复习次数（repetitions）、难易系数（easeFactor）
  • 第一次复习通过：下次复习安排在 1 天后
  • 第二次复习通过：下次复习安排在 6 天后
  • 之后每次通过：间隔 = 上次间隔 × 难易系数（约 2.5 倍递增）
  • 回答"Again"（完全忘了）：间隔重置为 1 天，从头开始

这意味着你轻松记住的词会越来越少出现，而你总是搞混的词会反复出现，直到真正掌握。

单词的掌握阶段

阶段条件含义
New（新）从未复习过（repetitions = 0）刚加入，还没见过面
Learning（学习中）复习间隔 < 7 天还不稳定，需要频繁复习
Young（巩固中）复习间隔 7～20 天开始记住了，复习频率降低
Mature（已掌握）复习间隔 ≥ 21 天记忆稳定，偶尔复习即可

如何使用闪卡

1

点击左侧导航 Review，页面显示今天待复习的单词数量。

2

点击 Begin Session 开始复习。单词顺序已随机打乱。

3

卡片正面：看到单词，回想它的意思（默默在心里回忆，不要着急翻牌）。准备好后点击 Show Answer。

💡 关键技巧 在翻牌前，一定要在脑子里主动回忆，哪怕只记住一点点也好。主动回忆（Retrieval Practice）是记忆加固的核心机制，被动看答案收效甚微。
4

卡片背面：显示单词的全部释义（包括所有义项）。对比你的回忆，诚实评估自己的表现，然后点击对应的评分按钮。

5

复习完所有单词后，显示本次 Session 的统计：各评分的数量分布。

四个评分按钮详解

Again
完全不记得
明天再来
Hard
有点印象
但想了很久才想起来
Good
正确回忆
有些费力
Easy
秒懂，毫无压力
很久后再见

每个按钮下方的小字（如"in 3 days"、"in 2 wk"）显示如果你按这个评分，下次复习会安排在什么时候。

评分诚实性很重要

  • 如果你勉强想出来了，应该按 Hard，不要按 Good——诚实才能让算法精准
  • 如果完全想不起来，一定按 Again，不要为了"让数字好看"按 Good
  • 算法会自动照顾你：Again 的词明天还会出现，直到你真正记住
⚠️ 复习时间建议 每天的复习量与你之前加词的速度正相关。如果某天复习量突然暴增（>50词），说明前段时间加词太激进，可以适当减缓词书的每日释放量。

八、每日推荐学习流程

以下是一套经过验证的高效学习流程，全程约 20～30 分钟，适合每天坚持：

第 1 步
2 分钟
打开软件，打卡签到 进入 Dashboard，点击 Check In。查看今天有多少词需要复习（Due Today）。
第 2 步
5～15 分钟
完成今日复习（Review） 点击 Review Now 进入复习。对每张卡片：先回忆，再翻牌，诚实评分。
复习量：通常 10～30 词，若超过 50 词说明积压了，连续几天清空就会好。
第 3 步
5 分钟
录入今日新词 把今天课堂、阅读、刷题中遇到的生词加入 My Words。建议 5～20 个为宜。
词书用户：新词已由词书自动释放，这步可以补充手动遇到的额外词汇。
第 4 步
10 分钟
生成并阅读有声文章（Generate Article） 选择 Today All（今天的新词+到期词）→ 主题随意或设定 → 生成 Medium 文章。
先静读，再开 0.8x 语速跟读，注意高亮词汇在语境中的用法。
可选加餐
精听朗读 + 跟读 将语速调到 1.0x 或 1.2x，跟着录音默读或大声朗读，练习英语语感和发音。
✅ 坚持的关键 每天 20 分钟、连续 30 天，比每周一次 3 小时学得更牢固。Dashboard 的 Streak 连续天数就是你最好的激励——别让那根链子断掉。

九、常见问题

Q：生成文章时报错"API 错误 401"

原因：API Key 不正确或已过期。
解决：重新到对应平台复制 Key，打开 Settings → 清空 API Key 框 → 重新粘贴 → Save Settings。

Q：生成文章时报错"API 错误 429"

原因：请求太频繁（速率限制），或账户余额不足。
解决：等 30 秒后重试；或登录平台检查账户余额并充值。

Q：生成文章时报错 CORS 或 Failed to fetch

原因：部分 AI 接口不允许从浏览器本地文件（file://协议）直接调用。
解决方案（按难度排序）：

  1. 换一个接口试试（DeepSeek 对浏览器调用最友好）
  2. 换用 Chrome 并允许跨域：在桌面新建 Chrome 快捷方式，在"目标"末尾加上 --disable-web-security --user-data-dir="C:\chrome-dev"，然后用这个快捷方式打开
  3. 用 VS Code 的 Live Server 插件打开项目（会变成 http://localhost 协议，大多数 API 都接受）

Q：朗读功能没有声音 / 声音列表是空的

原因：浏览器语音引擎还没初始化完毕，或系统没有安装英语语音包。
解决：刷新页面重试；如果 Windows 系统没有英语语音，去「设置 → 时间和语言 → 语言 → 添加语言 → English (United States)」，安装后重启浏览器。

Q：关掉浏览器后数据还在吗？

数据存在浏览器的 localStorage 里，只要不清除浏览器数据，关闭后重新打开数据都还在。建议定期在 Settings → Export Data 备份一份 JSON 文件到本地。

Q：换了新电脑 / 新浏览器怎么迁移数据？

1

在旧浏览器里：Settings → ↓ Export Data，下载 JSON 文件。

2

在新电脑/浏览器打开软件后，打开浏览器开发者工具（F12）→ Console 标签页。

3

粘贴以下代码（将 JSON_CONTENT_HERE 替换为 JSON 文件内容）：

const data = JSON_CONTENT_HERE;
localStorage.setItem('vm_words', JSON.stringify(data.words));
localStorage.setItem('vm_checkins', JSON.stringify(data.checkIns));
localStorage.setItem('vm_wordbooks', JSON.stringify(data.wordBooks || []));
localStorage.setItem('vm_settings', JSON.stringify(data.settings));
location.reload();

Q：词书里有几千个词，localStorage 放得下吗？

localStorage 有约 5MB 的限制。5000 个词（含释义）大约占 500KB～1MB，完全没问题。如果导入超大词书报错，可以把词书拆成多个部分分别导入。

Q：可以同时用多个 AI 接口吗？

目前 Settings 只存一个激活的接口。如果想临时换接口，进 Settings 修改 Provider 和 Key 即可，不影响已有数据。

十、进阶使用技巧

技巧 1：给高频搞混的词加对比释义

对容易混淆的词对（如 affect/effect、principle/principal），在 My Words 里都加上，并在释义中注明区别：

affect : (v.) to have an effect on（动词，影响）; 注意：不要与名词 effect 搞混
effect : (n.) a result or impact（名词，效果/影响）

这样生成的文章里两个词会同时出现，在语境中自然区分。

技巧 2：利用 Topic 生成特定场景的文章

把生词和特定话题绑定，特别适合备考时的专题积累：

  • Topic: environmental policy and climate agreements（环境类作文备考）
  • Topic: medical research and public health（医学类阅读）
  • Topic: entrepreneurship and startup culture（商业类）
  • Topic: education technology and pedagogy（教育类）

技巧 3：词书排序策略

如果你的词表是考试词汇，建议导入前先排序：

  • 按字母顺序：记一个词时能联想到同字母的词群
  • 按词频从高到低：先学最常见的词，性价比高
  • 按话题分组：将同一主题词汇放在一起，有助于联想记忆

技巧 4：调整词书每日目标

如果发现每天复习量太大（积压严重），说明每日新词太多。可以暂停当前词书（点 ⏸），等积压的复习清空后再恢复。不要硬撑——复习质量比数量更重要。

技巧 5：生成文章后存档阅读

浏览器有「打印为 PDF」功能（Ctrl+P → 另存为 PDF）。把特别好的文章存为 PDF，睡前可以离线阅读，无需网络。

技巧 6：巧用 GRE 级别拓展词汇边界

对于已经有六级 / 雅思基础的学习者，偶尔把 Level 设为 GRE / Academic，AI 会用更精妙的句式和词汇，让文章本身也成为学习素材（文章中非高亮词汇的精妙用法同样值得品味）。
