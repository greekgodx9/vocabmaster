📚 VocabMaster

AI 驱动 · 间隔重复 · 跨设备同步

打开方式

PC：浏览器打开 vocabmaster5.netlify.app

iPhone：Safari 打开 → 分享 → 添加到主屏幕 → 像 App 一样使用

添加到桌面后可离线使用。不需要 VPN，不需要下载。

加单词

My Words → + Add Words，每行一个：单词 : 释义

批量：Word Books → + New Word Book → 拖入 CSV/Excel → 每天自动释放

AI 生成文章

  1. 点 Generate Article
  2. 勾选想包含的单词
  3. 可选填主题，选长度和难度
  4. 点 Generate → 单词在语境中高亮
  5. 点高亮词看释义，点 ▶ 听朗读
需要 AI API Key。Settings 里选 DeepSeek（国内可用），去 platform.deepseek.com 注册充值 10 元即可。

复习

Review → 看词想释义 → 翻面 → 按记忆情况评级（Again / Hard / Good / Easy）。系统自动安排下次复习时间。

复习完可进入拼写测试。

同步

云同步：Settings → Account → 输入 Username + Password → Log In & Sync。两台设备用相同的账号密码，数据自动同步。

本地传输：Copy All Data → 微信发给另一台设备 → Import from File。

进度

Progress 页面查看学习状态分布、连续打卡天数、12 周热力图。

Dashboard 点 Check In 记录每日打卡。

常见问题

数据安全吗？数据存在本地浏览器，云同步加密隔离。API Key 只存你的设备。

能离线吗？添加到桌面后可离线复习。AI 生成文章和同步需要网络。

换设备？旧设备 Copy All Data → 新设备 Import from File，或用云同步账号登录。
